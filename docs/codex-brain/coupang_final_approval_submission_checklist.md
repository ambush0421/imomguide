# 쿠팡 파트너스 최종승인 제출 체크리스트

기준일: `2026-03-19`

참고 자료:
- 쿠팡 파트너스 공식 최종승인 가이드 PDF
- 활동 페이지와 실제 노출 화면이 일치하는지 검토하는 흐름 기준 정리

## 1. 활동 페이지 등록 문안

쿠팡 파트너스 활동 페이지 등록 시 아래처럼 정리해 두면 설명이 짧고 분명하다.

- 활동 페이지명: `마곡 코드찾기`
- 활동 페이지 주소: `https://loopincode.com/`
- 활동 방식 설명:
  `마곡 일반산업단지 업종코드 추천 및 입주 예비판정 정보를 제공하는 웹사이트이며, 쿠팡 파트너스 링크 또는 배너가 포함된 콘텐츠를 현재 사이트 내에서 운영합니다.`

## 2. 최종승인용 스크린샷 체크리스트

- 첫 화면에서 사이트 이름 `마곡 코드찾기`가 보이는지 확인
- 현재 접속 주소 `loopincode.com`이 보이게 캡처
- 쿠팡 링크, 배너, 위젯 중 실제 노출 요소가 화면에 보이게 배치
- 대가성 문구가 같은 화면에 함께 보이게 배치
- 푸터의 `운영자 정보`, `문의 안내`, `쿠팡 파트너스 안내`가 보이는 화면도 1장 준비
- PC 화면 1장, 모바일 화면 1장을 각각 준비

## 3. 대가성 문구 예시

아래 문구를 그대로 써도 무방하다.

`이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`

## 4. 제출 전 최종 점검

- 활동 페이지 등록 주소와 실제 운영 주소가 같은지 확인
- 링크 클릭 시 정상 이동하는지 확인
- 문의 채널이 실제로 연락 가능한 상태인지 확인
- 대가성 문구가 모든 제휴 게시물에 반복 노출되는지 확인
- 승인 신청 직전에 새로고침하여 최신 배포 화면으로 캡처했는지 확인

## 5. 현재 남아 있는 운영 메모

- 문의 채널은 아직 확정 정보가 없으므로, 승인 제출 전 실제 이메일 또는 카카오톡 채널을 반영하는 것이 안전하다.
- `imomguide.pages.dev`는 별도 리다이렉트 설정이 남아 있으면 최종적으로 `loopincode.com` 기준으로 정리하는 편이 좋다.
