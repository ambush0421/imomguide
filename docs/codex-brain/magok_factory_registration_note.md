# 마곡 산업단지 내 공장등록 가능 여부 메모

기준일: `2026-03-17`

## 결론

- `가능은 하지만 자동은 아님`
- `마곡 산업단지 내 지식산업센터`에서도 제조업 입주 자체는 가능하므로, 요건을 갖춘 제조업체는 공장등록까지 갈 수 있다.
- 다만 `입주 가능`과 `공장등록 가능`은 다르다.
- `연구개발업`, `정보서비스업`, `광고업`, `디자인업`처럼 제조시설이 없는 업종은 지식산업센터 입주는 가능해도 `공장등록` 대상은 아니다.

## 왜 가능한가

| 근거 | 내용 |
| --- | --- |
| 산업집적법 제28조의5 | 지식산업센터에는 `제조업`, 지식기반산업, 정보통신산업 등이 입주할 수 있다. |
| 산업집적법 제28조의2 | 지식산업센터 설립에도 `제조시설설치승인` 관련 규정이 준용된다. |
| 산업집적법 제16조, 시행규칙 제10조 | 공장설립등의 완료신고 후 `공장등록대장`에 등록하는 절차가 있다. |
| Factory On | 공장등록 신청 화면에서 `공장 소재지가 지식산업센터인 경우 먼저 선택`하도록 되어 있어, 지식산업센터 소재 공장등록 절차가 전제되어 있다. |
| 마곡 고시문 | 지식산업센터의 제조시설에 대해 `공장등록사항 확인`, `공장신설 승인 조건`을 별도로 두고 있다. |

## 마곡에서 특히 중요한 제한

| 항목 | 마곡 기준 |
| --- | --- |
| 제조시설 설치 가능 여부 | 가능. 다만 일반 제조공장이 아니라 `도시형공장` 성격의 제조시설이어야 한다. |
| 제조시설 면적 | `건축연면적의 20% 이하` |
| 연구시설 비율 | 원칙적으로 `연구시설용도 50% 이상`, 중소기업은 `40% 이상` |
| 추가 조건 | `연구개발과 제조시설 생산 간 연계성` 필요 |
| 관리기관 확인 | 사업개시 후 관리기관이 `공장등록사항`, 변경사항 확인 가능 |

## 실무 판정

| 상황 | 공장등록 가능성 |
| --- | --- |
| 마곡 지식산업센터에 입주하는 `제조업체`이고 실제 제조설비를 설치하며, 도시형공장 + 제조시설 20% 이하 + 연구시설 비율 유지 조건을 충족 | `가능` |
| 제조업 코드가 있어도 실제로는 사무실, 연구실, 영업소만 운영하고 제조설비가 없음 | `어려움` |
| 제조업이 아닌 순수 연구개발업, 정보서비스업, 광고업, 전문디자인업 등 | `불가` |
| 제조시설 비율 20% 초과 또는 연구시설 비율 미달 | `불가 가능성 높음` |

## 한 줄 정리

- `마곡 지식산업센터에서도 공장등록은 가능할 수 있다.`
- 다만 `제조업 입주 + 실제 제조시설 + 도시형공장 요건 + 제조시설 20% 이하 + 연구시설 비율 유지`를 모두 맞춰야 한다.
- 그래서 `지식산업센터 입주 가능`만으로는 부족하고, `공장등록 가능 여부`는 별도로 확인해야 한다.
