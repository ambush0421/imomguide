# PDCA 기록 규칙

이 폴더는 저장소 안에서 작업 단위별 PDCA 사이클을 남기는 용도로 사용합니다.

## 파일 규칙

- 파일명은 `YYYY-MM-DD-기능명.md` 형식으로 만듭니다.
- 한 작업 루프당 하나의 파일을 만들고, 같은 날 여러 루프가 있으면 기능명을 더 구체적으로 적습니다.
- 각 파일은 아래 4개 섹션을 기본으로 유지합니다.

## 기본 섹션

### Plan

- 왜 이 작업을 하는지
- 현재 문제 진단
- 구현 범위와 완료 조건

### Do

- 실제로 수정한 파일
- 핵심 구현 내용

### Check

- 실행한 검증 명령
- 통과 여부
- 남은 경고나 관찰 사항

### Act

- 다음 루프에서 이어서 볼 개선점
- 회고와 재사용할 규칙

## 연계 문서

- 상세 작업 체크리스트와 구현 계획은 `docs/codex-brain/`에 유지합니다.
- 이 폴더는 그 결과를 PDCA 관점으로 다시 정리하는 저장소용 기록입니다.
