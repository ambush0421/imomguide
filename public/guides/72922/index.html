이 가이드가 다루는 범위

제도업(72922)는 전문, 과학 및 기술 서비스업 안에서 연구·전문서비스 흐름으로 분류되는 업종입니다.

지식산업센터를 먼저 보되, 다른 구역 결과와 이유를 함께 놓고 비교해야 실제 상담에서 설명이 흔들리지 않습니다.

이 페이지는 원문 문서 전체를 그대로 옮긴 것이 아니라, 실제 상담과 검토 과정에서 바로 쓸 수 있도록 판단 순서와 체크포인트를 덧붙인 편집형 가이드입니다.

구역별 판단 요약

지식산업센터 가능

지식산업센터 5자리 코드 기준에서 바로 허용되는 업종입니다.

산업시설구역 불가

마곡 산업시설구역의 명시 허용 업종표에 직접 들어가지 않는 코드입니다.

산업시설구역은 관리기본계획에 적힌 허용 그룹과 prefix에 속한 업종만 기본 허용으로 봅니다.

이렇게 읽으면 빠릅니다

  1. 지식산업센터 결과부터 읽고 왜 가능으로 분류됐는지 확인합니다.
  2. 산업시설구역 비교 결과를 이어서 읽어 같은 업종이지만 어디서 더 보수적으로 보는지 정리합니다.
  3. 서울특별시고시 제2026-144호 75~76쪽 지식산업센터 입주업종·입주자격와 페이지 힌트를 따라 원문을 다시 확인합니다.

자주 묻는 질문

72922 제도업 업종은 마곡에서 가능한가요?

제도업(72922)는 지식산업센터 기준 가능으로 먼저 검토되며, 산업시설구역에서는 불가로 정리됩니다. 현재 화면 기준으로는 지식산업센터 우선 검토가 적합합니다.

제도업 업종은 왜 가능 판정을 받나요?

지식산업센터 5자리 코드 기준에서 바로 허용되는 업종입니다. 근거는 서울특별시고시 제2026-144호 75~76쪽 지식산업센터 입주업종·입주자격, 산업집적법 시행령 제6조 제2항를 먼저 보면 됩니다.

제도업 업종은 무엇을 추가로 확인하면 좋나요?

산업시설구역 비교 결과도 함께 보고 구역 선택 전략을 정하는 편이 좋습니다.
